安装

系统要求

Section titled “系统要求”
  • Mac：macOS 14 及以上，Apple Silicon
  • iPhone：iOS 17 及以上
  • Mac 上已安装并登录 Claude Code

暂不支持 Intel Mac、iPad 和安卓手机。不需要注册任何账号。

使用时 Mac 要保持开机。UULink 默认会阻止 Mac 闲置睡眠，但合上笔记本盖子后仍会睡眠，这时手机连不上。

1. 安装 Mac 端

Section titled “1. 安装 Mac 端”

让 Claude Code 帮你装

把下面这句话发给 Mac 上的 Claude Code，它会按 llms.txt 里的步骤检查系统、下载并安装 UULink，装好后你用手机扫码配对就行：

在 Mac 上下载最新的 UULink，文件名是 UULink-<版本>.dmg（也可以按 从源码构建 用 scripts/release-mac.sh 自行打包）。打开后把 UULink（UULink.app）拖进「应用程序」再启动。首次启动会弹出设置向导：

  1. 确认找到了 claude。没找到时按向导里的命令安装，然后点「重新检测」。
  2. 最后一步显示配对二维码，先不要关，装好手机端后用它配对。

之后 UULink 常驻菜单栏，再配对其他设备时点菜单栏里的 UULink 图标，选「配对新设备…」（⌘ P）。可以在「设置 › 通用」中开启「登录时打开 UULink」，并在「系统设置 › 通用 › 登录项」中允许 UULink。

提示“无法验证开发者”

自行打包且未使用 Developer ID 签名的安装包，在其他 Mac 上打开会被拦截。到「系统设置 › 隐私与安全性」点「仍要打开」即可。

2. 安装 iPhone 端

Section titled “2. 安装 iPhone 端”

iOS 端目前为测试版，尚未上架 App Store，有两种安装方式：

  • TestFlight：向开发者索取邀请，收到后在 TestFlight 中安装。
  • 自行构建：按 从源码构建 用 Xcode 装到自己的设备（用你自己的 Apple ID 签名）。设备上需要开启「开发者模式」；使用免费 Apple ID 签名的版本 7 天后失效，需要重新安装。

安装后打开 UULink，点「扫描二维码添加 Mac」，扫描 Mac 上的配对二维码（也可以用系统相机扫）。手机没有相机时，在 Mac 的配对窗口点「拷贝链接」，通过「通用剪贴板」等方式发到手机后选「或粘贴配对链接」。配对码 10 分钟内有效、只能用一次。

首次连接时 iOS 会询问是否允许访问本地网络。允许后同一网络中的手机和 Mac 直接连接，速度更快；拒绝也能用，只是改为经中继连接。

App 内嵌 iroh 节点，不需要安装其他 App，也不占用系统 VPN。

需要任务完成通知时，在 App 的「设置 › 通知」点「开启通知」；之前拒绝过的，点「前往“设置”开启」。

3. 开始使用

Section titled “3. 开始使用”
  1. 添加项目：浏览 Mac 上的目录，选中项目文件夹。
  2. 选择或新建 git worktree。
  3. 新建会话，或打开已有会话（包括在 Mac 终端里直接跑的会话）。
