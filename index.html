开始使用加入 TestFlight

现在是测试版，iPhone 端需要 TestFlight 邀请。需要 Apple Silicon 的 Mac（macOS 14 以上）和 iOS 17 以上的 iPhone，不用注册账号。

为什么用 UULink

0.1 秒

在外面用也很快

手机和 Mac 直接相连，中间不绕路。用手机流量也一样，一次往返不到 0.1 秒1，点下去 Mac 马上就有反应。消息先压缩再发，流量能省一半多2。

一条不丢

网络断了，消息不会丢

没有信号的时候也可以发，等网络恢复会自动发出去，而且只执行一次。断开期间的输出，连上后会接着显示。

无中心

没有中心服务器，更安全

UULink 没有中心服务器，也不用注册账号，你的代码和对话不会留在任何人的服务器上。手机和 Mac 之间全程端到端加密，没有一处被攻破就能泄露所有人数据的地方。安全设计详解

其他功能

  • 用你现有的 Claude Code账号和订阅照常用，不需要另外配置 API Key。
  • 终端里的对话，手机上接着聊在 Mac 终端里开始的 Claude Code 会话，手机上也能看到并继续。
  • 成果直接发到手机Claude 做好的报告、截图和网页，可以发到手机上直接打开。
  • 多台 Mac 一起管家里和公司的 Mac 都能加上，项目和分支随时切换。
  • 不用折腾网络不用装 VPN，也不用做任何网络设置，扫一下码就能连上。你平时用的代理也照常工作。
