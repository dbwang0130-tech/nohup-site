Supported agents

UULink runs coding agents that you install on your own Mac. It currently supports 8: Claude Code, Codex, Cursor, opencode, Qoder CLI, DeepSeek Harness, Pi and Antigravity. You choose one when you start a session; an existing session keeps the agent it was created with.

The basics work the same with every agent: sending messages, viewing tool calls, switching models, and browsing and resuming past sessions. The differences are described in each section below and in the comparison at the end.

UULink charges nothing extra for any agent. The subscription only covers the number of Macs and projects, push notifications, sending files and web pages to your phone, image attachments and Live Activity. Each agent uses your own account, subscription or API key, and any usage fees are charged by that provider.

Adding an agent in UULink

Section titled “Adding an agent in UULink”

Install and sign in to the agent on your Mac first. Then open UULink on the Mac and go to Settings › Agent:

  • The list on the left shows the agents you’ve added, each with its detected version, or Not Detected if the executable can’t be found. Claude Code, Codex, opencode and Pi are in the list by default.
  • Click + at the bottom left to add another agent (Cursor, Qoder CLI, DeepSeek Harness, Antigravity); click − to remove the selected one.
  • The right side shows the selected agent’s settings: display name, the Enable switch, the executable (detected automatically, or choose one with Choose…), and environment variables (for API keys, proxies and so on). Click Detect Again after making changes.

When an agent isn’t detected, UULink shows how to install it and a link to its website. Once detected, you can choose it when starting a new session on your iPhone. The first step of the setup assistant shown on first launch uses the same view.

Claude Code

Section titled “Claude Code”

A coding agent by Anthropic that reads and edits code and runs commands in the terminal. Website · Install docs

  • Install: run the official install script in Terminal, curl -fsSL https://claude.ai/install.sh | bash, or install with Homebrew: brew install --cask claude-code.
  • Sign in: run claude and follow the prompts to sign in to your Claude account in the browser (requires a Pro, Max, Team, Enterprise or Console account). UULink uses this sign-in and subscription; no separate API key is needed.
  • In UULink: in the list by default. If the sign-in expires, you can sign in again from your iPhone: in the sidebar, open this Mac’s … menu and choose Sign In to Claude Code….
  • Features: everything is supported, including permission modes (with Plan), subscription usage, continuing terminal sessions on your phone, and deleting sessions.

Codex

Section titled “Codex”

A coding agent by OpenAI (Codex CLI). Website · Install docs

  • Install: run the official install script in Terminal, curl -fsSL https://chatgpt.com/codex/install.sh | sh, or install with npm, npm install -g @openai/codex, or Homebrew, brew install --cask codex. If the ChatGPT desktop app is installed, the Codex bundled with it is detected automatically.
  • Sign in: run codex login to sign in with your ChatGPT account, or use an OpenAI API key.
  • In UULink: in the list by default. You can also sign in from your iPhone: start it on the account page and authorize with a ChatGPT device code.
  • Features: permission modes and model switching, approving commands and edits on your phone, continuing terminal sessions, and deleting sessions. Warnings from Codex appear as banners in the session.

Cursor

Section titled “Cursor”

The command-line coding agent by Cursor (Cursor CLI). Website · Install docs

  • Install: run the official install script in Terminal, curl https://cursor.com/install -fsS | bash.
  • Sign in: run agent login to sign in to your Cursor account in the browser, or set CURSOR_API_KEY in UULink’s environment variables.
  • In UULink: click + in Settings › Agent and add Cursor. UULink looks for the cursor-agent executable.
  • Features: Agent / Plan / Ask modes, switched in the session settings; approve commands and edits, answer its multiple-choice questions and review its plans on your phone.
  • Limitations: sessions can’t be deleted.

opencode

Section titled “opencode”

An open-source coding agent that works with many model providers. UULink supports OpenCode 2. Website · Install docs

  • Install: run the official OpenCode 2 install script in Terminal, curl -fsSL https://opencode.ai/v2/install | bash, or install with npm: npm install -g @opencode/cli.
  • Sign in: run opencode auth login to connect a model provider. The built-in free models need no sign-in.
  • In UULink: in the list by default; UULink uses opencode’s own credentials.
  • Features: models are chosen as provider / model, the mode (build / plan) is switched in the session settings, and you can approve commands and edits on your phone and delete sessions. It doesn’t use Claude Code’s permission modes.

Qoder CLI

Section titled “Qoder CLI”

A command-line coding agent by Alibaba. Website · Install docs

  • Install: run the official install script in Terminal, curl -fsSL https://qoder.com/install | bash.
  • Sign in: run qodercli login to sign in to your Qoder account.
  • In UULink: click + in Settings › Agent and add Qoder CLI.
  • Features: Default, Accept Edits and Bypass Permissions modes and model switching; approve commands and edits on your phone and delete sessions.
  • Limitations: no Plan mode.

DeepSeek Harness

Section titled “DeepSeek Harness”

An open-source agent harness by DeepSeek; the command is dsh. It is currently in developer preview. Website · Docs

  • Install: after installing Node.js, run npm install -g @deepseek-ai/dsh in Terminal. This command is derived from the npm package name rather than quoted from the official docs; follow the official docs if they differ.
  • Sign in: no sign-in; it uses a DeepSeek API key. Create one on the DeepSeek Platform, then add the DEEPSEEK_API_KEY environment variable for DeepSeek Harness in Settings › Agent.
  • In UULink: click + in Settings › Agent and add DeepSeek Harness.
  • Features: approve commands and edits on your phone, switch models and delete sessions.
  • Limitations: UULink shows only sessions started in UULink; sessions started in dsh’s own web interface don’t appear.

Pi

Section titled “Pi”

A minimal, extensible open-source coding agent by Earendil that works with many model providers. Website · Docs

  • Install: run the official install script in Terminal, curl -fsSL https://pi.dev/install.sh | sh, or install with npm (requires Node.js 22.19 or later): npm install -g --ignore-scripts @earendil-works/pi-coding-agent.
  • Sign in: run pi and enter /login to sign in to a subscription or enter an API key. You can also add your provider’s API key environment variable (such as ANTHROPIC_API_KEY) for Pi in Settings › Agent.
  • In UULink: in the list by default.
  • Features: model switching, browsing and resuming history (including sessions started in Terminal), and deleting sessions.
  • Limitations: Pi doesn’t support MCP, so it can’t send files or web pages to your phone or control the Mac desktop yet. It has no permission modes; commands and edits run without approval on your phone.

Antigravity

Section titled “Antigravity”

A coding agent by Google. UULink uses it through Google’s official ACP server (agy_acp_server). Website · Docs

  • Install: run the following command in Terminal to download Google’s official ACP server and unpack it where UULink detects it automatically (~/Library/Application Support/UULink/acp/antigravity):

    You can also unpack it elsewhere, then select Antigravity in Settings › Agent and click Choose… to point to agy_acp_server.par.

  • Sign in: in Settings › Agent › Antigravity on the Mac, click Sign In to Google… and complete authorization in the Mac’s browser. You can also start sign-in from the account page on your iPhone, but authorization still happens in the Mac’s browser. Alternatively, set the GEMINI_API_KEY environment variable to use a Gemini API key.

  • In UULink: off by default. Click + in Settings › Agent to add Antigravity; sign in once it is installed and detected.

  • Features: permission modes (with Plan) and model switching; approve commands and edits on your phone.

  • Limitations: sessions can’t be deleted. UULink gives Antigravity its own configuration folder, so only sessions started in UULink appear.
